# Lehsun Local Growth Playbook

## Phase 1 Positioning

Lehsun should present itself the same way across the website, Google Business Profile, Instagram, Facebook, and local citations:

- Primary offer: North Indian catering for birthdays, housewarmings, baby showers, family gatherings, and festive events.
- Primary areas: Ebbsfleet Valley, Dartford, Gravesend.
- Secondary offer: fresh daily menu for collection in Ebbsfleet Valley, DA10, with local delivery within 2 miles only.
- Brand angle: proper North Indian flavour, not toned down, with separate veg and non-veg kitchens.

## Core Business Description

Use this as the default long-form profile copy:

> Lehsun is a North Indian catering business based in Ebbsfleet Valley, serving Ebbsfleet, Dartford, Gravesend and nearby Kent. We cater for birthdays, housewarmings, baby showers, family gatherings and festive events with proper flavours that feel like home. We also post a fresh daily menu for collection in Ebbsfleet Valley, with local delivery within 2 miles on qualifying orders.

## Google Business Profile Checklist

- Set the primary category to the most catering-led option available.
- Keep North Indian cuisine or Indian restaurant only as secondary categories if they support discovery without confusing the main offer.
- List service areas as Ebbsfleet Valley, Dartford, Gravesend, Northfleet, and nearby Kent areas you actually serve for catering.
- Make the website link point to the homepage while the homepage remains catering-led.
- Add services for birthdays, housewarmings, baby showers, family gatherings, festive catering, vegetarian catering, and bespoke event menus.
- Upload event photos, buffet spreads, plated dishes, kitchen hygiene proof, and team-at-work shots.
- Ask every satisfied customer for a Google review with a prompt that mentions the event type and town.
- Publish one post each week alternating between catering proof, menu proof, customer reviews, and festive/event reminders.

## Content Rules For All Area Pages

- Do not clone the same copy with town names swapped.
- Use only truthful service claims and real delivery coverage.
- Mention daily menu only as a secondary local offer when relevant.
- Include at least one town-specific proof item before publishing.
- Link back to the main catering page and relevant menu/contact pages.
